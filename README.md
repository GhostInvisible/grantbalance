# Грантовый баланс: симулятор директора новой НКО (Godot 4)

Вы директор новой НКО. Сами проектируете смету гранта (600 000 руб.), получаете деньги траншами,
проводите мероприятия, закупаете оборудование, оформляете людей и документы, согласовываете изменения
с фондом и проходите проверки. Проиграть можно в любой момент, цель - дойти до конца.

## Как запустить
1. Распакуйте архив. 2. Godot -> Import -> project.godot. 3. F5.

## Экспорт в HTML5
Project -> Export -> Web -> Export Project (index.html). Открывать через веб-сервер
(например, `python -m http.server`). Сохранения лежат в хранилище браузера.

## Игровой цикл
1. Проектирование: выбор позиций сметы (оплата труда, мероприятия, оборудование, аренда, админ. расходы). Фонд проверяет заявку.
2. Каждый месяц 3 действия: дела проекта, бухгалтерия, консультация, отдых.
3. Дело проекта = выбор варианта -> (согласование с фондом, если вариант меняет смету) -> комплект документов -> запись в журнал по статье.
4. Ошибки скрыты до проверки (или до сверки с бухгалтером). Проверки: плановые (месяцы 3, 6, 9, 12) и внезапные.
5. Нецелевое использование (изменение без согласования, о котором не сообщили) - проигрыш. Сообщить фонду можно до проверки через сверку.
6. Итог: концовка и отчёт «почему так закончилось».

## Структура
- autoload/game_state.gd - правила, нарушения, проверки, сохранения
- data/game_data.gd - ВЕСЬ КОНТЕНТ: позиции сметы, договоры, документы, кейсы приёмки, события, концовки
- scripts/main.gd - экраны и игровой поток
- scripts/base_ui.gd - тема, анимации, HUD, профиль, награды
- scripts/yard_view.gd, icon_view.gd - рисунки

## Важно
Правила учебные, донор не конкретный. Перед реальным обучением сверьте лимиты, виды договоров и
перечни документов с требованиями настоящего фонда и юристом или бухгалтером.

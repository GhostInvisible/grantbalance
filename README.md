# Грантовый баланс — обучающий симулятор для НКО (Godot 4)

## Как запустить
1. Распакуйте архив.
2. Godot -> Project Manager -> Import -> выберите `project.godot`.
3. Если Godot предложит конвертировать проект в вашу версию (4.7.x), согласитесь.
4. Нажмите F5.

## Экспорт в HTML5
1. Editor -> Manage Export Templates -> установите шаблоны вашей версии.
2. Project -> Export -> Add... -> Web.
3. Export Project, имя файла `index.html`.
4. Файлы нужно открывать через веб-сервер (не двойным кликом):
   `python -m http.server` в папке экспорта, затем http://localhost:8000
   Для публикации подойдёт itch.io (загрузить ZIP, тип "HTML").
Проект использует GL Compatibility, подходит для Web. Формат экрана: вертикальный 540x960.

## Структура
- `autoload/game_state.gd` — правила, показатели, проверка отчётов
- `data/game_data.gd`     — ВЕСЬ КОНТЕНТ: события, чеки, глоссарий (правится без знания кода)
- `scripts/main.gd`       — интерфейс (строится кодом)
- `scenes/main.tscn`      — один корневой узел

## Как добавить событие
Откройте `data/game_data.gd`, скопируйте любой блок в `EVENTS`, измените тексты и эффекты.
Поле `ok: false` отправляет решение в итоговый разбор ошибок.

## Важно
Правила (лимит косвенных расходов 15%, перерасход 10% и т.д.) — учебные упрощения.
Реальные требования зависят от донора и года; сверяйте с ними перед использованием в обучении.

## Что нового
- Двор рисуется кодом и меняется вместе с результатом проекта.
- Персонажи: Вера (бухгалтер), Игорь (куратор фонда), Миша (волонтёр).
- Акции с уровнями, закупки, найм помощников, второй грант в 6-й месяц.
- Мини-игры: «Субботник» (собери мусор) и «Разнеси чеки» на время.

## Вариативность (каждая игра разная)
- Выбор проекта: двор, берег реки или школьный сад.
- Случайный куратор (строгий, обычный, лояльный) и случайные цены.
- Профиль организации на втором уровне: Эко-школа или Зелёный патруль.
- Решения запускают продолжения историй в следующие месяцы (data/game_data.gd, FOLLOWUPS).
- Грант на 5-7 месяце: три предложения из пяти.
- Картинка меняется по сезонам, от акций, покупок, команды и уровня.

## Отбор в Школу НКО (по мотивам игровых отборов в вузы)
Сингл-кампания (12 месяцев) -> вердикт -> турнир кандидатов (3 раунда против 5 соперников) -> концовка.
- 12 концовок: 3 победных, 3 средних, 6 проигрышных. Коллекция и награды сохраняются между запусками.
- Средний путь затягивает игру: можно продлить проект на 6 месяцев или сыграть дополнительный раунд.
- Навыки (общение, аналитика, документы, лидерство) и звания от Новичка до Эксперта по грантам.
- Главы сюжета на 4, 7 и 10 месяце, продолжения историй, ежемесячные поручения.
- Мини-игры: субботник, блиц-чеки, поиск нарушений, питч донору.
- Весь контент (главы, события, концовки, вопросы) лежит в data/game_data.gd.

## Пассивные эффекты и сложность
- Каждый месяц показатели меняются сами: естественный спад + эффекты покупок, сотрудников, программ и решений.
- В HUD рядом с каждой шкалой видно прогноз «+N/мес». Итоги месяца показывают, что и откуда изменилось.
- Сложность выбирается при старте (Лёгкая / Обычная / Сложная). Цифры баланса: autoload/game_state.gd (PLAN, _decay_mult).
- Все покупки, программы, сотрудники и способы работы с документами: data/game_data.gd (ITEMS, STAFF, ACTIVITIES, DOC_ACTIONS).
